# Southampton's Possible Cargo Routes

Child-friendly static MapLibre dashboard based on **1,000 single-candidate associations** between Southampton commodity records and recorded outward voyages.

## Interpretation

Each association has one outward voyage sharing the commodity record's archive reference and year window. These are evidence-based possible connections, not proof that a named ship carried or delivered the commodity. Routes use an approximate modern sea network and are not reconstructed historical tracks.

## Publish on GitHub Pages

Upload `index.html`, `.nojekyll`, and this `README.md` to a repository, then choose **Settings → Pages → Deploy from a branch → main → /(root)**.
